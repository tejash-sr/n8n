KEY NEW NODES (vs Phase 2)
──────────────────────────

  Route by category   (Switch)
                      notes: "4 named outputs + fallback. Fallback (extra
                              output) catches any unexpected category and
                              routes to the errors tab — never silently
                              drops an item."
                      options.fallbackOutput = "extra"

  Lookup <cat>        (Sheets, operation=lookup)
                      For each of leads/support/spam/other, range=<cat>!A:A,
                      lookup column = message_id.
                      retryOnFail=true, maxTries=3, waitBetweenTries=5000

  Already in <cat>?   (IF)
                      Condition: $json[0].message_id is empty
                      true  → Append <cat>
                      false → Duplicate skipped (<cat>)

  Duplicate skipped (<cat>)   (Set)
                      notes: "Idempotency short-circuit. Emits
                              duplicate_skipped=true and a human-readable
                              skip_reason so the executions log explains
                              the no-op."
                      fields: duplicate_skipped=true,
                              skip_reason=already_in_<cat>_tab

  Append <cat>        (Sheets, operation=append)
                      Explicit column mapping (NOT "map all fields"):
                        leads:    message_id, received_at, sender_email,
                                  sender_domain, subject, body_preview,
                                  priority, confidence, status=NEW,
                                  created_at={{$now.toISO()}}
                        support/spam/other: similar tab-specific columns
                      retryOnFail=true, maxTries=3, waitBetweenTries=5000

  Log unknown category to errors  (Sheets append → errors tab)
                      notes: "Switch fallback target. Captures the rare
                              case where the LLM returns a category outside
                              the 4 allowed enums."
